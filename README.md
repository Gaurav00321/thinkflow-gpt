# ThinkFlowGPT

ThinkFlowGPT is a powerful AI-powered coding assistant and chat platform that helps developers streamline their workflow and boost productivity.

## Features

- 🤖 **AI-Powered Code Assistant**: Advanced coding assistance with real-time execution capabilities
- 💬 **Interactive Chat Interface**: Seamless communication with AI for problem-solving
- 📊 **Business Dashboard**: Comprehensive analytics and usage tracking
- 🔐 **Secure Authentication**: Enterprise-grade security measures
- ⚡ **Real-time Execution**: Quick and efficient code processing
- 🔄 **Workflow Automation**: Streamlined development processes
- 📱 **Responsive Design**: Full support across all devices
- 🎨 **Modern UI/UX**: Built with Next.js and Tailwind CSS

## Tech Stack

- **Framework**: Next.js
- **Styling**: Tailwind CSS
- **Authentication**: Custom auth implementation
- **State Management**: Custom hooks and stores
- **UI Components**: Shadcn UI

## Getting Started

1. Clone the repository (requires proper authorization)
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables:
   Create a `.env.local` file with the necessary configuration

4. Run the development server:
   ```bash
   npm run dev
   ```

## Project Structure

- `/app` - Next.js application routes and pages
- `/components` - Reusable React components
- `/hooks` - Custom React hooks
- `/lib` - Utility functions and shared logic
- `/public` - Static assets
- `/styles` - Global styles and themes
